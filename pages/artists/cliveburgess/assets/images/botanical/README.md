# Botanical Anatomical Images

Add 10-13 light anatomical botanical line drawings in black and white to this directory.

## Where to find similar images to the roots on Last Place:

### Best Sources:

1. **Unsplash** (Free, no attribution required)
   - https://unsplash.com/s/photos/botanical-illustration
   - https://unsplash.com/s/photos/black-and-white-plants
   - Search for: "botanical drawing", "plant anatomy", "botanical illustration"

2. **Biodiversity Heritage Library** (Public Domain)
   - https://www.biodiversitylibrary.org/
   - Over 150,000 free vintage botanical illustrations
   - Use Flickr account for easier browsing: search "biodiversity heritage library"

3. **NYPL Digital Collections** (Public Domain)
   - https://digitalcollections.nypl.org/
   - Search: "botanical illustration" or "plant anatomy"
   - Filter by "Free to Use and Reuse"

## Image Requirements:

- **Style**: Light anatomical line drawings, similar to root illustrations on Last Place
- **Format**: JPG or PNG
- **Color**: Black and white or grayscale
- **Naming**: botanical_1.jpg, botanical_2.jpg, ... botanical_13.jpg
- **Quantity**: 10-13 images total

## How it works:

- The page randomly selects 3 images from the pool each time it loads
- Images appear with 3-second intervals between them
- Random positioning and sizing (same as Last Place roots)
